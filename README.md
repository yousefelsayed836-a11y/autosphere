# Autosphere

Static storefront demo. Serve this folder over HTTP; products, prices and cart are illustrative and there is no backend.

The following models have modified material roughness and metalness, conversion to metallic roughness where necessary, and geometry and texture compression:

- [2015 Nissan Versa Sedan 1.6](https://sketchfab.com/3d-models/2015-nissan-versa-sedan-16-18af87c9490e4acb80a46b70ca8d86ed) by [Ddiaz Design](https://sketchfab.com/ddiaz-design), [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Approximate Sunny reference.
- [2013 BMW 335i Gran Turismo (F34)](https://sketchfab.com/3d-models/2013-bmw-335i-gran-turismo-f34-e4f91073e4374de5a3ff0858f25400d2) by [Ddiaz Design](https://sketchfab.com/ddiaz-design), [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Approximate 320i reference.
- [2013 Mitsubishi Lancer ES5](https://sketchfab.com/3d-models/2013-mitsubishi-lancer-es5-cb8e125879d5430da61372d4949af8ad) by [tonielpro520](https://sketchfab.com/tonielpro520), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Approximate 2015 Lancer reference.

Nissan and BMW models are for non-commercial use only. Replace them with appropriately licensed models or obtain permission before operating a commercial store. Hero artwork and logo were generated for this demo.
